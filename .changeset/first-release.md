First release: intake engine, Anthropic adapter, screen capture, React hooks and the ready-made widget.

`@elicitor/core` has three entry points: the main one for hosts (`createIntake`, the `ModelAdapter` and `ReportStore` contracts, `createMemoryStore`, wire types), `@elicitor/core/testing` for the fake models, and `@elicitor/core/engine` for the stateless single-turn building blocks.
